Info on how this WebXR passthrough boilerplate was set up:

    A quote from the above site I used for passthrough:
    "webgl renderer must be transparent (alpha:true in threejs) and background color (0x00000,0)
    canvas css must be transparent (background:none)
    must enter immersive-ar (not immersive-vr session)"
